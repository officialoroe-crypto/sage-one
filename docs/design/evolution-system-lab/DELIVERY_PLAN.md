# Design Lab Delivery Plan

This plan sequences independent design work. It does not authorize app integration.

## Track A — Source asset preparation
1. Preserve the approved source image unchanged.
2. Obtain original/high-resolution source assets if available: SAGE logo, Buddha, mountain, moon, skyline, stage emblems and coin.
3. If only a flattened board exists, create separate non-destructive crops and document their coordinates and resolution.
4. Verify each crop against the original before treating it as reusable.
5. Keep any missing asset explicitly marked as source extraction required.

## Track B — Evolution inventory
1. Create a gallery with exactly thirteen stage cards.
2. Match stage order, emblem footprint and labels.
3. Produce Low/Mid/High variants for every stage (39 visual states).
4. Compare the 13-card row at the same aspect ratio as the reference.
5. Keep all final palette values provisional until owner approval.

## Track C — Progression explanation
1. Diagram Skill Upgrade and Money Upgrade as separate paths.
2. Preserve Learn → Practice → Evidence → Skill → Opportunity → Work Earn → Lifetime Achievement → Evolution.
3. Clearly state that Spark is separate from Evolution.
4. Clearly state that withdrawals do not reduce lifetime Evolution.
5. Do not invent rank thresholds, earning targets or backend award logic.

## Track D — Motion prototype
1. Storyboard the nine required transition beats.
2. Create the Bronze High → Silver Low keyframe sequence.
3. Check emblem readability during every beat.
4. Prepare reduced-motion alternative.
5. Keep timing and effects exploratory pending visual review.

## Track E — Owner review package
- Landscape board reconstruction.
- 13-stage gallery.
- 39-state contact sheet.
- Transition storyboard.
- Asset inventory with source and crop details.
- Provisional token register and unresolved decisions.
- Side-by-side fidelity checklist.

## Explicitly out of scope
- Flutter or React production implementation.
- Changes to main app navigation or screens.
- Backend economy, Spark, rank thresholds, or award rules.
- New claims about money-to-rank conversion.
- Final palette approval.
