# Reference Board Layout Notes

## Source and intended use
The owner-provided reference is a landscape design board. The board itself—not a generated interpretation—is the visual authority. This document describes its visible information architecture so a designer can reconstruct the board while comparing directly to the original image.

## Reading order and regions
1. **Top-left hero region:** SAGE orbital logo above/alongside the SAGE ONE wordmark; subtitle “Unified 13 Evolution System”; short line “Same SAGE. New Evolution.” The Himalayan scene includes Mount Everest, moon, Buddha statue, cosmic sky and distant illuminated settlement.
2. **Top-middle concept region:** two side-by-side cards: Skill Upgrade and Money Upgrade. Each has a distinctive icon, short explanatory statement and a compact bullet list.
3. **Top-right flow and rules:** horizontal progression flow at top; numbered Key Rules panel beneath.
4. **Middle-left Evolution gallery:** title “The 13 Evolutions”; thirteen vertical rank cards in one horizontal row, each with emblem, number and stage name. A material-accent legend appears below the cards, followed by a note that the exact palette is conceptual and not locked.
5. **Middle-right intensity panel:** Low / Mid / High comparison cards, each with the same SAGE emblem and increasing particles/glow. A progression strip below shows Current Evolution (High) → Evolution Transition → Next Evolution (Low).
6. **Bottom-left example sequence:** Bronze Low, Bronze Mid, Bronze High, Evolution Transition, After Transition (Silver Low), each in a separate preview card with brief explanatory notes.
7. **Bottom-right identity comparison:** “Not This” full brown interface takeover versus “This” blue/black interface with material accent only; beneath it, permanent SAGE identity and Evolution material accent examples.

## Layout principles
- Keep the hero image as a distinct, large identity area rather than shrinking it into a tiny logo thumbnail.
- Use a clear cyan-outline panel system on a near-black/blue background.
- Maintain the compact, technical infographic character of the concept board.
- Keep text high contrast and avoid tiny type when adapting for presentation.
- Stage gallery is the main visual inventory; do not let explanatory panels overpower it.
- Keep the intensity comparison and transition strip adjacent so the relationship is obvious.
- Do not rearrange the reading order without an explicit redesign brief.
- The source is landscape. Mobile screen adaptation is a separate design exercise and is not part of this design-only board reconstruction.

## Fidelity method
Use the original reference image side-by-side at its native aspect ratio. Check panel boundaries, card widths, alignment, title hierarchy, spacing, and artwork placement against the image. This text is a guide to the board's structure, not a replacement for direct image comparison.
