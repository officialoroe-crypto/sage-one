## Rules for sampling
- A sampled pixel is affected by glow, antialiasing, compression and surrounding light; it is not automatically a design token.
- If colors are sampled from the original image, record sample location, source dimensions and whether it is a highlight, body, shadow or glow.
- Keep sampled values in a separate **measured draft** table.
- Do not promote measured draft values to approved palette values without the owner's confirmation.
- Do not use broad saturation or hue shifts to simulate a material; tune material accents locally.
- Preserve contrast and the blue/black base across all stages.
