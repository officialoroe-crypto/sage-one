# Composition and Asset Inventory

## Reference composition
The approved board is a wide dark-blue/black cinematic presentation with thin cyan outlines and structured panels. Its regions include:

1. **Identity / hero scene** — SAGE logo, SAGE ONE title, “Unified 13 Evolution System” heading, Himalayan mountain scene, moon, Buddha statue, night sky and distant settlement.
2. **Core concept** — two progression paths: Skill Upgrade and Money Upgrade.
3. **The flow** — Learn → Practice → Evidence → Skill → Opportunity → Work Earn → Lifetime Achievement → Evolution.
4. **Key rules** — lifetime Evolution, Spark separation, achievement-led rank, stable base UI and permanent SAGE identity.
5. **13 Evolution gallery** — all thirteen stage emblems and labels in the fixed order.
6. **Low / Mid / High comparison** — three intensity presentations of one stage.
7. **Bronze example sequence** — Bronze Low, Bronze Mid, Bronze High, transition, Silver Low.
8. **Identity/material comparison** — avoid full interface color takeover; keep SAGE identity permanent and material as an accent layer.

## Required original visual assets
- Exact approved SAGE orbital logo/emblem.
- Exact Buddha statue artwork.
- Exact mountain / Mount Everest landscape artwork.
- Exact moon and night-sky/cosmic background.
- Exact settlement / horizon artwork.
- The thirteen stage emblems as shown.
- Coin/Spark-related visual asset(s) from the approved source material.
- Typography and border treatment from the source image.

## Asset handling rules
- Prefer extracting/cropping original source artwork from the approved source file or obtaining the original source assets. Do not regenerate a visually similar Buddha, mountain, moon or logo and present it as identical.
- Preserve the original source image unchanged in the owner library.
- Record source, crop, dimensions, aspect ratio and any transformations for each derived asset.
- Avoid destructive edits. Store crops/exports as separate derivatives.
- If an asset is not separately available, mark it **source extraction required** rather than inventing a replacement.
- Any unavoidable responsive crop must be documented and checked against the reference.

## Layout adaptation
This board is a landscape design reference. A future mobile adaptation should be designed as a separate responsive composition, not by arbitrarily squeezing the board into a phone. Keep all original content and visual relationships; owner review is required before considering the mobile layout final.
