# Evolution Design Review Checklist

## Source fidelity
- [ ] Compare directly against the locked original image, not a text-only interpretation.
- [ ] SAGE logo/emblem shape, glow and placement preserved.
- [ ] Buddha statue preserved.
- [ ] Mountain / Mount Everest scene preserved.
- [ ] Moon, stars, cosmic sky and distant settlement preserved.
- [ ] Coin / Spark visual language preserved and not confused with Evolution.
- [ ] Typography, cyan outlines, dark background and panel hierarchy checked.
- [ ] No unapproved crop, hue, saturation, brightness, contrast or scale changes.

## Thirteen stages
- [ ] Exactly 13 stages.
- [ ] Names and order match STAGES.md.
- [ ] All 13 emblems represented.
- [ ] No missing or duplicated rank.
- [ ] Low / Mid / High are states within each stage, not extra stages.
- [ ] Material accents do not recolor the entire interface.
- [ ] SAGE blue/black identity remains permanent.

## Progression rules
- [ ] Skill/achievement path is distinct from money/capability path.
- [ ] Spark is separate from Evolution.
- [ ] Withdrawal never reduces lifetime Evolution.
- [ ] No invented thresholds or reward rules.
- [ ] Progress claims are tied to evidence/achievement, not merely a displayed balance.

## Motion
- [ ] All nine transition beats present and in correct order.
- [ ] Bronze High → Silver Low example is understandable.
- [ ] New rank emblem resolves clearly.
- [ ] Reduced-motion alternative exists.
- [ ] Motion does not obscure labels or SAGE identity.

## Handoff / isolation
- [ ] Work remains under `docs/design/evolution-system-lab/`.
- [ ] No Flutter, React, backend, API, or app navigation files changed.
- [ ] No changes made to the locked source image.
- [ ] Undecided items are explicitly marked for owner approval.
- [ ] Future app integration is a separate decision and separate work claim.
