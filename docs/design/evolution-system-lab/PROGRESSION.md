# Progression Model

## One journey, two separate paths

### Skill upgrade — defines Evolution
Evolution identity reflects:
- Knowledge
- Skills
- Experience
- Capability
- Completed achievements
- Demonstrated progress

The skill path changes the user's visible Evolution material and identity.

### Money upgrade — improves system capability
Economic progression can support:
- Earning
- Economic achievement
- System progression / capability
- Access to higher-level functions

Money is not a direct purchase of Evolution rank. Do not conflate Spark balance, lifetime money earned, or withdrawals with the user's skill/achievement rank.

## Core rules
1. Evolution is a lifetime achievement. Withdrawal does not reduce it.
2. Spark is separate from Evolution and belongs to the platform economy.
3. Money supports the journey, but skill and achievement define Evolution.
4. The base UI stays the same; only visual Evolution layers evolve.
5. SAGE blue + black identity never disappears.

## Suggested conceptual information hierarchy
- Current Evolution name and stage number.
- Current intensity state (Low / Mid / High).
- Evidence-based progress toward the next stage.
- Skills, experience and completed achievements that contribute.
- Separate economic capability/progress panel.
- Clear explanation that Spark and Evolution are different systems.

This is an information architecture proposal derived from the approved concept board, not a decision to change backend thresholds or economy rules. Keep thresholds and actual award rules sourced from the backend contract when/if a future integration is separately approved.
