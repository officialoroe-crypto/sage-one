# SAGE ONE Major-Work Rule

**Use this rule before every major task.**

1. **Recover first:** Read the current project instructions, decision log, saved references/assets, and relevant code before planning or editing. Do not rely on memory or guess.
2. **Audit before action:** Inventory requirements, files/screens, existing work, bugs, conflicts, and missing assets. Make no changes during the audit.
3. **Preserve intent:** Treat approved instructions and designs as requirements. Record every detail with a stable ID and trace it to the relevant screen/component, asset, implementation, and test. Never replace, omit, or invent details silently.
4. **Separate the steps:** (A) Audit → (B) Requirements/gap report → (C) Plan and approval → (D) Small, traceable implementation batches → (E) Tests and evidence → (F) Preview for user review → (G) Apply/merge/deploy only with explicit approval.
5. **Keep one source of truth:** Update the requirements registry, project state, and decision log after each batch. Mark items as LOCKED, APPROVED, NEEDS DECISION, PROPOSED, REJECTED, IMPLEMENTED+VERIFIED, or BLOCKED.
6. **Protect the project:** Inspect status/branches before edits; preserve uncommitted work; never reset, overwrite, or deploy blindly. Use free/existing resources unless paid use is explicitly approved.
7. **Report honestly:** State what was inspected, changed, tested, passed, failed, and remains. Never claim a change, test, or deployment succeeded without evidence.

**Default:** If this rule is pasted into a task, follow it first. If anything important is missing or conflicting, flag it before implementation.
